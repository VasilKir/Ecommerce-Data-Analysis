# E-commerce Data Analysis

This project analyzes e-commerce sales and customer behavior using SQL, Python, and Tableau.

## Tools

- SQL (BigQuery)
- Python
- Pandas
- NumPy
- Matplotlib
- Tableau

## What was analyzed

- Sales performance
- Traffic channels
- Customer types (Registered vs Guest)
- Devices
- Product categories
- Countries
- Conversion Rate
- Average Order Value (AOV)

## Files

- `Portfolio.ipynb` – Python analysis
- `README.md` – Project description
